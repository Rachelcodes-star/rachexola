RACHEXOLA MINERALS WEBSITE

HOW TO OPEN
1. Download and extract the ZIP.
2. Open the RACHEXOLA_Minerals_Website folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.

FEATURES
- Responsive modern design and navigation
- Mineral cards with search and category filters
- Clickable mineral detail pop-ups
- Mineral uses and Rwanda overview
- Five-question interactive quiz with score
- Contact form demo (does not send or store messages online)

NOTES
- Internet is needed to load the remote photos.
- This is a front-end website. A live contact form or database needs a backend.
- Information is introductory; use official sources for current mining statistics and regulations.
